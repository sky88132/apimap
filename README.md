# 사이 · 거리 측정 웹앱

출발지와 도착지를 Nominatim으로 검색하고, 검색 결과의 실제 장소를 선택해 거리를 계산하는 한국어 웹앱입니다. API 키, Redis, 데이터베이스, 별도 환경변수 없이 동작하는 정적 HTML/CSS/JavaScript 프로젝트입니다.

## 실행

Node.js 22 이상에서 다음 명령을 실행하고 http://localhost:3000 에 접속합니다. 패키지 설치는 필요하지 않습니다. 파일을 직접 여는 `file://` 방식은 지원하지 않습니다.

```sh
npm run dev
```

Windows PowerShell 실행 정책으로 `npm.ps1` 오류가 나면 `npm.cmd run dev`를 사용하세요. 검증 명령도 `npm.cmd run check`, `npm.cmd test`로 실행할 수 있습니다.

## GitHub → Vercel 배포

1. 이 폴더의 파일을 GitHub 저장소에 업로드합니다.
2. Vercel에서 **Add New → Project**를 선택하고 저장소를 Import합니다.
3. **Framework Preset: Other**, **Root Directory: 저장소 루트**를 선택합니다.
4. Build Command와 Install Command는 Override를 켜서 빈 값으로 둡니다. Output Directory는 기본값(루트)을 사용합니다. UI에서 값을 요구하면 `.`을 입력합니다.
5. 환경변수를 추가하지 않고 Deploy합니다.

서버 함수나 빌드 산출물이 필요하지 않습니다. `server.js`는 로컬 미리보기 전용입니다. GitHub Pages 등 일반 정적 호스팅에서도 실행 가능합니다.

## 사용

- 출발지와 도착지를 입력하고 각각 검색을 누릅니다. Enter로도 검색할 수 있습니다.
- 결과 목록에서 원하는 장소를 선택합니다. OSM에 등록되지 않은 장소는 검색되지 않을 수 있습니다.
- 자동차 도로 거리 또는 직선거리를 선택하고 거리 계산하기를 누릅니다.
- 총거리 하단의 **지도에서 보기**를 누르면 OpenStreetMap이 새 탭으로 열립니다. 자동차 모드는 두 좌표의 길찾기, 직선 모드는 두 장소를 포함하는 주변 지도입니다. 직선 연결선이나 두 마커를 표시하는 기능은 아닙니다.
- 도로 경로가 없거나 서비스 장애가 있으면 오류를 안내합니다. 직선거리를 도로 거리로 대신 표시하지 않습니다.

## 공개 API 사용 제한 — 배포 전 필독

**공개 Nominatim은 앱 전체 사용자를 합쳐 최대 초당 1회 요청만 허용합니다. 이 구성은 다수 사용자의 전체 요청량 제한을 보장하지 않습니다. 공개 서비스로 널리 배포하거나 사용량이 증가하기 전에 전체 요청량을 제한할 수 있는 구조 또는 별도 Nominatim 제공자를 준비해야 합니다.**

사용자가 요청한 공개 Nominatim을 사용하며, 개발자/운영자가 [Nominatim 사용 정책](https://operations.osmfoundation.org/policies/nominatim/) 준수에 책임을 집니다. 소규모 사용을 위한 다음 조치를 적용했습니다.

- 자동완성이나 입력 중 요청 없이, 검색 버튼 또는 Enter로만 조회합니다.
- 동일 브라우저의 요청은 최소 1.1초 간격을 둡니다. Web Locks 지원 브라우저는 같은 출처의 여러 탭도 직렬화합니다.
- 검색 결과를 브라우저 localStorage에 24시간 캐시합니다. 저장소 접근이 불가능해도 앱은 동작하나 캐시가 유지되지 않습니다.
- 브라우저 Referer로 서비스 출처를 전달하고 OSM 저작자와 정책 링크를 표시합니다. `file://` 대신 HTTP(S)로 서비스하세요.
- 사용자 검색어는 Nominatim으로, 선택한 두 좌표는 OSRM으로 전달됩니다. 개인정보나 기밀 주소를 검색하지 마세요.
- `config.json`의 `nominatimUrl`, `routingUrl`을 변경하면 프런트엔드 코드 수정 없이 API 제공자를 바꿀 수 있습니다. Nominatim/OSRM 호환 응답과 브라우저 CORS 지원이 필요합니다. 공개 설정이므로 비밀 키를 넣지 마세요.

Vercel의 서버리스 인스턴스별 메모리나 브라우저 캐시는 앱 전체의 공유 제한 장치가 아닙니다. Redis나 환경변수가 필요 없다는 점이 무제한 무료 API 사용이나 대규모 운영 가능성을 의미하지는 않습니다.

[OSRM API](https://project-osrm.org/docs/v5.24.0/api/#route-service)의 공개 데모 서버는 가용성 보장이 없습니다. 도로 거리는 자동차 경로 기준이며, 실시간 교통·통행 제한의 완전한 반영을 보장하지 않습니다. 한국을 포함한 일부 지역은 OSM 도로 데이터 연결 상태에 따라 경로가 없거나 우회할 수 있습니다. 실제 여행 전 경로를 확인하세요. 직선거리는 평균 지구 반지름을 사용하는 Haversine 공식으로 계산합니다.

## 검증

```sh
npm run check
npm test
```

배포 후 서울역/경복궁 등으로 검색 → 선택 → 도로 거리 → 지도 링크를 확인하고, 직선거리·출발지 교환·결과 없는 검색도 확인하세요. 외부 API의 장애·차단·CORS 제한은 앱 코드만으로 해결할 수 없습니다.
